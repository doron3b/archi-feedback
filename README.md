# Archi Feedback

Public issue tracker for Archi bugs, blockers, and concrete improvement suggestions.

Reports should describe the Archi operation, expected behavior, actual behavior, and abstract reproduction steps. Use synthetic examples such as Session A and Story B.

**Everything posted here is public.** Do not include user or customer information, project or private repository names, URLs, filesystem paths, real Story/Board/Session identifiers or content, prompts, conversations, source code, raw logs, screenshots, attachments, secrets, or credentials.

The planned in-app flow prepares a local draft, lets the user review and edit the complete public payload, and submits only after an explicit Send Report action. The hosted submission service is not available yet.

A report is not a promise of a fix. Triage and any internal development work are separate; this tracker does not automatically create development tasks or repair sessions.
