# Archi Feedback

Archi Feedback V1 prepares a local report, notifies the user, and offers Review/Edit before opening a native email composer. The user reviews the email and sends it from their own mail account. Sending exposes the sender's email address to the recipient. Archi does not send email in the background or track delivery.

Describe only the Archi problem and use abstract or synthetic examples such as Session A and Story B. Do not include project or repository names, filesystem paths, Story/session content or identifiers, prompts, conversations, source code, raw logs, secrets, environment data, diagnostics or attachments.

This repository remains available for documentation and optional manual public reporting. **GitHub Issues are public.** The in-app email path does not publish to GitHub and does not require a GitHub account.

The former hosted service snapshot has been retired and removed from the current tree. Historical service code is obsolete and should not be deployed. Archi Feedback V1 requires no hosted feedback service, GitHub App, server credentials or backend.

A report is not a promise of a fix. Reports do not automatically create Stories, synchronize a Board or start repair sessions.
